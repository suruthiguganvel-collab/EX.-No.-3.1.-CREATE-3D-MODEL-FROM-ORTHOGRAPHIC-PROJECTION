# EX. No.3.1. CREATE 3D MODEL FROM ORTHOGRAPHIC PROJECTION
## DATE:

## AIM:
To create a complete three-dimensional mechanical component from the given two-dimensional orthographic projection drawing using Autodesk Fusion 360 software. The main objective of this experiment is to understand the conversion of engineering drawings into 3D models by using various sketching, dimensioning, modifying and solid modelling operations.
The experiment also helps to develop practical knowledge of different geometric construction tools and modelling techniques. The given component is constructed by interpreting its front view, top view and right-side view. The specified dimensions, circular portions, curved surfaces, rectangular sections and extended features are considered while developing the final model.

## REQUIREMENTS:
1.Autodesk Fusion 360: The primary Computer-Aided Design (CAD) software used for 3D modeling and sketching.  
2.Windows 10: The operating system required to run the software smoothly.  
3.16 GB of RAM: Required for smooth system performance (integrated graphics with 1 GB or more is recommended).  
4.Internet Connection: A download speed of 2.5 Mbps or faster, and an upload speed of 500 Kbps or faster.

## PROCEDURE:
The step-by-step instructions to convert a 2D sketch into a 3D model are as follows: 
Open New File & Select Sketch Icon:
Launch Autodesk Fusion 360, open a new design file, and then select the sketch icon from the toolbar.  
Select the Plane for Sketching:
Choose the appropriate working plane (such as the XY, YZ, or XZ plane) on the Cartesian coordinate system to begin drawing.  
Use Sketching Features:
Use basic sketching tools—such as line, circle, arc, rectangle, polygon, etc.—to draw the required 2D profile according to the given specifications.  
Use Sketch Modifying Features:
Utilize modification tools like cut, trim, mirror, move, etc., to edit, refine, and clean up the sketch as needed

![image](https://user-images.githubusercontent.com/113594316/198551199-8d9b7f6c-6ea7-4d59-8e8c-173f2b5e088f.png)

4. Use Sketch Modifying Features
Description:
"Use sketch modifying features (cut, trim, mirror, move, etc.,) to edit the sketch."  
Detailed Explanation:
After drawing the basic 2D profile using standard shapes, you often need to clean up or adjust the geometry.  
Modifying tools like cut/trim are used to remove unwanted overlapping lines or intersections.  
Tools like mirror help duplicate symmetric parts across a centerline, and move lets you reposition elements accurately according to the orthographic design specifications.

![image](https://user-images.githubusercontent.com/113594316/198551220-c7aa6694-4427-48e2-9d91-cd7e9615d651.png)

5.	Inspecting and Verifying Sketch Dimensions:
After completing the 2D sketch, use the Inspect tool to double-check and measure all key dimensions, including lengths, angles, radiuses, and spacing.  
This step ensures that the geometry strictly adheres to the orthographic specification before translating it into 3D, preventing errors downstream.

![image](https://user-images.githubusercontent.com/113594316/198551270-45875855-43a7-4471-af35-bd10cd9dd153.png)

6.	Finalizing the Sketch:
Once the drawing is fully defined and accurately dimensioned, click the 'Finish Sketch' option located on the toolbar.  
This closes the 2D editing workspace and transitions Autodesk Fusion 360 back into the 3D solid modeling mode.

![image](https://user-images.githubusercontent.com/113594316/198551309-8d7ac6c8-6740-479f-8186-195c89823fda.png)

7.	Converting 2D Profile to 3D Model (Extrude):
Select the Extrude tool from the Solid modeling ribbon.  
Choose the closed 2D profile created in the sketch step, specify the exact thickness or extrusion depth given in the drawing, and click OK to generate the solid 3D part.

![image](https://user-images.githubusercontent.com/113594316/198551340-fe1f3b48-df79-44ef-a4ae-ff1cd22503ea.png)

8.Generating Drawing Sheet (ISO Standard):
After finalizing the 3D model, navigate to the Design Workspace dropdown and select Drawing from Design to create a standard technical drawing sheet formatted per ISO standards.  
This automatically places projected views (front, top, side) along with standard dimensions for industrial manufacturing and documentation.

![image](https://user-images.githubusercontent.com/113594316/198551370-54509915-ec69-4862-9c17-156d61a83b11.png)
